# PDF File Organizer Automation

**Python · PowerShell · Excel · PDF Processing**

An Excel-based automation tool designed to simplify repetitive document management tasks, including folder creation, PDF splitting, file distribution, and bulk file renaming.

## Features

- **Folder Generator** — Create multiple folders with customizable naming patterns and sequential numbering.
- **PDF Splitter** — Split PDF documents into separate files based on predefined page ranges.
- **File Distributor** — Automatically copy or move files into designated folders.
- **Batch Renamer** — Rename multiple files using customizable naming rules.

## Technology Stack
