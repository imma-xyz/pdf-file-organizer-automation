# PDF File Organizer Automation

PDF File Organizer Automation is a lightweight, Excel-based document management tool designed to simplify repetitive file organization tasks.

Built with Python and PowerShell, this project automates common document handling processes through configurable Excel templates, allowing users to manage large numbers of files without manually processing them one by one.

### Key Features

- **Automated Folder Creation** — Create multiple folders with customizable naming patterns and sequential numbering.
- **PDF Splitting** — Split PDF documents into separate files based on predefined page ranges.
- **File Distribution** — Automatically copy or move files into designated folders.
- **Batch File Renaming** — Rename multiple files using customizable naming rules and suffixes.

### Technology Stack

- Python
- PowerShell
- Microsoft Excel
- pypdf
- openpyxl

### Project Goals

- Reduce repetitive manual document management tasks.
- Improve file organization consistency.
- Minimize human errors during document processing.
- Provide a reusable solution for different administrative and document management workflows.

The project aims to make document organization faster, more consistent, and accessible to users with minimal programming knowledge.
